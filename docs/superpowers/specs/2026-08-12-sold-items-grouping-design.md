# 物品归类与中文名称设计

## 目标

优化库存与挂单表格的浏览顺序：盯价中和已挂出的物品优先显示，已售出记录集中放在表格末尾并默认折叠。物品名称优先显示 Steam 官方简体中文名称，同时保留英文原名用于所有 Steam 接口操作。

## 修改范围

- 修改前端 `index.html` 的列表排序、分组、名称渲染和搜索联动。
- 修改库存解析和物品数据字段，以保存 Steam 返回的官方中文名称。
- 不修改状态值、价格计算、库存匹配或上架流程。
- 不改变现有行内编辑、批量选择和只读规则。

## 中文名称规则

1. Steam 库存请求使用简体中文语言参数，读取描述中的官方本地化名称。
2. 英文 `market_hash_name` 继续作为物品内部名称和 Steam 接口键，不允许被翻译结果覆盖。
3. 新增独立的中文显示名称字段；界面以中文名为主标题，英文原名为小字副标题。
4. 中文名称随库存同步自动保存，已保存的名称可用于已售出记录展示。
5. Steam 未返回有效中文名称时只显示英文原名，不调用第三方翻译服务。
6. 搜索同时匹配中文名和英文原名。

## 列表规则

1. `watching` 和 `listed` 为最高优先级，保持它们在 API 返回结果中的相对顺序。
2. 其他非 `sold` 状态排在其后，同样保持原相对顺序。
3. `sold` 状态集中放在表格末尾。
4. 已售出区域前显示一行分组标题：`已售出（N）`。
5. 已售出区域首次加载时默认折叠，点击分组标题切换展开或折叠。

## 搜索行为

- 搜索仍匹配名称、游戏、状态和最后消息。
- 名称搜索同时匹配中文显示名称和英文原名。
- 搜索词命中已售出记录时，临时显示已售出分组及匹配行。
- 清空搜索后恢复用户当前的折叠状态；初始状态仍为折叠。

## 实现方式

- 在 `render()` 中对 `state` 建立稳定排序后的展示数组，不修改原始 `state`。
- 在第一条已售出记录前插入一个表格分组行。
- 用单一布尔状态记录已售出区域是否展开。
- `applyTableFilter()` 同时控制普通行、已售出行和分组标题的可见性。
- 库存解析保留英文 `market_hash_name`，并单独返回 Steam 官方本地化名称。
- 后端保存中文显示名称，但价格、库存和上架仍只读取英文原名。

## 验收条件

- 页面无搜索词时，盯价中和已挂出记录位于顶部。
- 其他活动状态位于中间。
- 已售出分组位于末尾、数量正确且默认折叠。
- 点击分组标题可正常展开和折叠。
- 搜索已售出物品时能看到匹配结果。
- 有 Steam 官方中文名称时，表格显示中文主标题和英文副标题。
- 没有中文名称时，英文原名正常显示且功能不受影响。
- 使用中文或英文名称均能搜索到对应物品。
- 价格查询、库存匹配和上架继续使用英文原名。
- 已售出记录继续保持只读且不可批量勾选。
- 页面保持有效 UTF-8，不出现乱码或 JavaScript 语法错误。
